## About Me

I'm a Computer Science student from the Philippines who enjoys building things that sit between **design and code**.

I care about the small details: spacing, motion, layout, interaction flow, and whether someone can understand an interface without fighting it. Right now, my focus is on becoming better at frontend development, UI/UX design, and creating web apps that feel intentional.

- Currently building with **React**, **TypeScript**, and **Tailwind CSS**
- Interested in **frontend development**, **UI/UX**, and interactive web experiences
- Exploring better workflows with **AI coding tools**
- Open to internships, collaborations, and projects where I can keep improving
